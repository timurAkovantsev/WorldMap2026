# WorldMap2026 🗺️

Интерактивный десктопный редактор игрового мира с процедурной генерацией карты. Проект разработан на **C# (.NET / Windows Forms)** в рамках учебного задания с упором на чистую архитектуру и паттерн **MVP**.

---

## 📌 Описание проекта (ТЗ)
Приложение представляет собой редактор карты, в котором пользователь может создавать ландшафты, расставлять объекты и управлять игровым миром. 

**Основные требования из ТЗ:**
* **Процедурная генерация:** Карта генерируется автоматически с различными типами местности (трава, вода, песок, горы).
* **Правила размещения:** Объекты не должны накладываться друг на друга, а их постройка зависит от типа местности под ними (например, мельницы строятся только на траве или камнях).
* **Уникальная механика с пеньками:** При удалении дерева оно сначала превращается в пенек, и только повторное удаление уничтожает его окончательно.
* **Кастомные объекты:** Цветы имеют более 5 случайных вариантов текстур и могут расти «под» другими объектами (не блокируют клетки).
* **Кастомизация:** Возможность изменять цвета типов местности через стандартный `ColorDialog`.
* **Интерфейс и UX:** Использование кастомных иконок, курсоров мыши, а также звуковое сопровождение при успешных или ошибочных действиях.
* **Отрисовка:** Осуществляется через классический класс `Graphics` на элементе `PictureBox`.

---

## 🏛️ Архитектура и паттерн MVP
Главный фокус проекта — **строгое разделение ответственности** по паттерну MVP (Model-View-Presenter):
* **Model (Модель):** Содержит всю бизнес-логику, сетку карты (`MapModel`), типы клеток и данные об игровых объектах (`GameObject`). Модель ничего не знает про интерфейс.
* **View (Вьюшка):** Форма (`MainForm`) и рендерер (`MapRenderer`). Отвечают исключительно за отрисовку графики, обработку кликов мыши и показ кнопок.
* **Presenter (Презентер):** Связующее звено (`MapPresenter`). Слушает события от Вьюшки, проверяет правила через `PlacementRules`, управляет сохранением через сервисы и обновляет Модель.

## 📁 Структура проекта

```text
WorldMap2026/
│
├── Model/                  # Бизнес-логика и данные
│   ├── Items/              # Игровые объекты (Дерево, Мельница, Цветок, Поле)
│   ├── MapModel.cs         # Модель карты и ячеек (Зубчатый массив)
│   └── PlacementRules.cs   # Правила коллизий и размещения объектов
│
├── Presenter/              # Логика взаимодействия
│   ├── MapPresenter.cs     # Главный презентер (координатор)
│   └── IMapView.cs         # Интерфейс и DTO-структуры для связи с View
│
├── View/                   # Пользовательский интерфейс и графика
│   ├── MainForm.cs         # Главная форма Windows Forms
│   ├── MapRenderer.cs      # Отрисовка тайлов и спрайтов через Graphics
│   └── MapSizeDialogForm.cs# Кастомное окно ввода размеров карты
│
└── Services/               # Сервисы и генерация
    ├── MapGenerator.cs     # Процедурная генерация биомов
    └── JsonWorldStorage.cs # Сохранение и загрузка мира в формат JSON
```
